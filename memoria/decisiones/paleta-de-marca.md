# paleta de marca

La web era clara con botones naranjas, pero el logo y el feed eran negro, blanco y plateado: parecían dos empresas.
**Decisión**: la web sigue clara (se lee mejor en móvil y es más cercana para negocios de barrio) y el **naranja es el color de marca** en todo.
- Azul marino `#0B192C` / slate `#1E293B`: fondos y textos.
- Blanco `#FFFFFF`. Naranja `#F97316` (hover `#EA580C`): botones, detalles y palabras clave. Gris `#64748B`: texto secundario.
- Tipografía: Plus Jakarta Sans.
- Logo: retocar, no cambiar. Plano, sin degradados; "W" y "WEB" en naranja; versión solo "OW" para el perfil de Instagram.
