# no inventar datos del cliente

Lo que no se sabe (horario, precios, equipo, reseñas, Instagram, fotos) va como marcador visible `[...]` (en ROIG 44, en amarillo) y en una lista de pendientes del README. Las reseñas de ejemplo se marcan como tales o la sección se oculta hasta tener reales.
Solo se usan datos reales comprobables (por ejemplo, la nota de Google Maps de una captura).
**Regla**: nunca publicar reseñas, precios u horarios inventados como si fueran del cliente.
