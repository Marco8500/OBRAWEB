# modelo web con mantenimiento

**Contexto**: hasta ahora se probaba con pago único (ver [[precio-pago-unico-sin-cuota]]).
**Qué se decidió (en principio)**: vender **web básica + mantenimiento con un pago mensual**, y el **chatbot 24/7 como añadido** aparte. Las cifras, la permanencia, si hay pago de alta y qué cambios entran en el mantenimiento se deciden en la llamada con el [[productor-de-ventas]].
**Oferta de bienvenida (09/11)**: al contratar, el primer año de dominio es gratis (lo pagamos nosotros, unos 10–15 €) y el primer mes de mantenimiento va incluido; la cuota se paga desde el segundo mes.
**Precios fijados (19/11)**: web servicio completo 450 € + 21 % IVA; web completa + chatbot 550 € + 21 % IVA. Son fijos, sin presupuestos. Están en el chatbot de OBRAWEB. No está apuntado si son pago único o cómo encajan con la cuota de mantenimiento: preguntarlo antes de ponerlos en el dossier.
**Regla**: mientras no estén cerradas, no poner cifras en ningún material. Al cerrarlas, actualizar esta nota y el dossier `ventas/dossier-ventas.html`.
