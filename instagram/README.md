# Instagram / TikTok de ObraWeb

- `normas/`: reglas de publicación (3 reglas obligatorias de los reels, formatos, paleta, sin precio).
- `guiones/`: guiones (`.json`) y textos con hashtags (`.txt`) de cada publicación.
- `scripts/`: generadores. `voz.sh` + `reel.py` (reels, vía `crear.sh`), `carrusel.py`, `historia*.py`, `imagen_*.py`. `instalar.sh` descarga la voz (piper es_ES-davefx-medium).

Los vídeos, imágenes, audios y modelos no se suben al repositorio.
